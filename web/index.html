Key distinction

                  
The target states the answer. Facts state the inputs.

                

              

              

                

                  target
                  
Predicted event

                  
Example: a swing and miss on this slider.

                

                

                  when · versus
                  
Compared conditions

                  
Example: a prior fastball against no prior fastball.

                

                

                  facts
                  
Known inputs

                  
Example: count, batter side, and pitch shape.
